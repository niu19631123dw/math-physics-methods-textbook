# 数学物理方法：从物理问题出发

> 工具在问题后面出场，不在前面等着。  
> 毕竟我们不是数学家。

## 这是什么

一本以**物理问题为骨架**组织的《数学物理方法》讲义。不从数学分支出发，而从具体物理问题出发：**先让读者感到卡住，再引入工具。**

- **全书 / 单文件阅读**：[数学物理方法-讲义.pdf](数学物理方法-讲义.pdf)
- **分章源文件**：`00-导论.md` 到 `07-张量与黎曼几何.md`，以及附录 A–G
- **全文 Markdown**：[数理方法讲义-全文.md](数理方法讲义-全文.md)

## 章节结构

| 章 | 主题 | 核心工具 |
|---|---|---|
| 0 | 导论 | 地图、读法、三条判断 |
| 1 | 振动与波 | 分离变量、本征模、Fourier 级数、行波 |
| 2 | 圆与球 | Bessel、Legendre、球谐、级数解法 |
| 3 | 点源与响应 | δ 函数、Green 函数、边值问题、多极展开 |
| 4 | 留数定理 | 留数、Kramers–Kronig、保角映射 |
| 5 | 变换 | Fourier/Laplace、卷积、因果性 |
| 6 | 变分法 | Euler–Lagrange、作用量、Rayleigh 商 |
| 7 | 张量与黎曼几何 | Christoffel 符号、测地线、Riemann 张量 |

附录：A 数学约定｜B 判断清单｜C 数值演示｜D 计算题答案｜E 矢量微积分｜F 特殊函数速查｜G 母题对照

## 这本书的特点

1. **问题驱动**：第 1 章从“弦为什么会以某些频率振动”开始，第 2 章从“鼓为什么没有明确音高”开始。
2. **判断点体系**：每章末尾列出“这个操作什么时候合法、坏了会怎样、怎么察觉”。附录 B 是全书判断点的汇总和“症状 → 病因”诊断表。
3. **不追求数学体系的完整，但保住“什么时候会坏”**：定理给结论和适用条件，证明只在说明物理意义时展开。
4. **代码验证**：附录 C 的 Python 代码都很短，可以逐段运行。

## 编译

需要 XeLaTeX（含 ctex、tikz、pgfplots）：

```bash
cd build
# 生成正文与附录
python md2tex.py
# 三遍编译（目录需要多次迭代）
xelatex main.tex
xelatex main.tex
xelatex main.tex
```

- `build/main.tex`：版式与封面
- `build/md2tex.py`：把 Markdown 转成 LaTeX
- `build/makefull.py`：生成全文 Markdown
- `build/figs/`：插图（TikZ）与数据文件
- `build/gen_figs.py`：生成图中的数值数据
